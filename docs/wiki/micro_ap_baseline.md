# Micro-AP 비교 프로토타입

## 상태

3-AP 기반 짧은 교대 턴을 시험한 비교 프로토타입이다. 삭제하지 않고 기준선으로 보존 중이다.

## 현재 선택

프로젝트의 주 시간 모델은 M010이 아니라 M011 Action-Cost Time이다.

이 페이지는 과거 실험을 잊지 않고 이후 시간 시스템을 재평가할 때 비교 대상으로 사용하기 위해 남겨둔다.
