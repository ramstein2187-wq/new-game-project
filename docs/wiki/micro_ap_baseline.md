# Micro-AP 비교 프로토타입

## 상태

3-AP 기반 짧은 교대 턴을 시험한 역사적 비교 실험이다. 현재 주 시간 모델인 M011을 선택한 뒤, 별도 정리 브랜치에서 M010 전용 장면·스크립트·테스트를 퇴역시키고 결정 근거 및 과거 구현은 마일스톤 문서와 Git 기록으로 보존한다.

## 현재 선택

프로젝트의 주 시간 모델은 M010이 아니라 M011 Action-Cost Time이다.

이 페이지는 과거 실험의 가설과 비교 근거를 유지하기 위한 아카이브다. 현재 실행 가능한 Micro-AP 테스트룸이 있다고 가정해서는 안 된다. 필요하면 과거 Git 커밋에서 복구해 별도 worktree로 실험한다.
