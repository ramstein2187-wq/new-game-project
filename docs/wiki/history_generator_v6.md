# 사건 기반 역사 생성 코어 v6 Phase A

`codex/history-generator-v6-core`의 독립 실험이다. 기본 `HistoryGenerator`는
여전히 v5이며 기존 v2–v5 출력과 Canon 규칙은 변경하지 않았다.

초기 지역 상태에서 가능한 사건 유형을 고르고, 참여자를 별도로 선택한 뒤,
검증된 효과를 상태 복사본에 원자적으로 적용한다. 성공한 사건만 기록하며
동일한 초기 상태와 JSON 사건 로그를 재생하면 최종 상태를 재구성한다.
분열·이주·재점유·관계 변화·지역 사고·물건 이동/유실의 여섯 규칙을 제공한다.

현재 제공하는 것은 세력 계보, 출처가 보존된 인구, 장소 소유권과 손상,
관계, 물건의 보관 이력이다. 손상된 시설의 재점유는 기술 복구가 아니며,
사건의 시간적 선후를 동기로 해석하지 않는다. 규칙이 실제로 사용한 선행
조건과 접근 불가 지역에서의 이동만 명시적 원인으로 기록한다.

1,000개 Seed에서 실패와 재생 불일치가 없었고, 실제 상태가 후속 후보를
바꾸는 연결을 확인했다. 다만 47.3%가 여섯 인구집단에 따른 세력 상한에
도달했고, 관계·이주·유실의 교대 반복 및 장기적 폐허 수렴은 남는다.
이는 작은 코어의 조합 가능성 검증이며, 세계 전체의 창발성이나 플레이
재미를 검증한 결과는 아니다.

플레이어에게 제공할 수 있는 차이는 지역의 접근성·소유권·주민·물건 위치지만,
이번 작업은 이를 실제 월드맵, Actor 행동, 아이템, UI에 연결하지 않는다.
다음 단계에서는 작은 지역에서 이러한 차이가 탐험·위험·선택에 어떻게
작용하는지 별도 검토해야 한다.
