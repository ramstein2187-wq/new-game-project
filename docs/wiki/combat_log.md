# 구조화 전투 로그

## 개요

단순 문자열 기록 대신 전투 결과를 구조화된 이벤트로 남긴다.

## 구성

- `CombatEvent`: 이벤트 종류, Actor/Target/Action ID, 시간, 비용, 중요도, 관찰자, 이유 코드, 결과 데이터
- `CombatEventLog`: 제한된 인메모리 이벤트 기록
- `CombatLogFormatter`: 플레이어용 문장과 개발자용 상세 trace 분리

## 원칙

AI의 내부 점수를 그대로 노출하지 않고 행동을 만든 reason code를 이벤트와 함께 보존한다. 일반 모드는 사소한 이동/대기를 숨길 수 있고 상세 모드에서 확인할 수 있다.

## 한계

현재는 완전한 LOS/지각 시스템이 아니며, 이벤트 저장도 영속적인 세계 이벤트 버스가 아니라 제한된 전투 로그다. 퀘스트나 사회 시스템이 이벤트를 소비하기 시작하면 별도 사건 모델을 결정해야 한다.
